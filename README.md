A runnable recreation of the uploaded 15.8-second screen recording.

## What is included
- Four circular navigation bubbles: Home, Profile, Settings and Messages
- Active bubble expands into a rounded pill and reveals its label
- Distinct active colors: blue, purple, green and orange
- Hover, click, keyboard focus and responsive mobile behavior
- Small CSS editor-style panel and a Copy CSS button

## Run
Unzip the project and open `index.html` in a modern browser. No dependencies or build step are required.

## Source fidelity
The recording shows the rendered navigation and a small code-editor view, but the source text is too small to reliably transcribe in full. This project recreates the visible layout, bubble expansion, icon/label behavior and color variations. The labels and implementation details are reconstructed; this is not the original source repository or a byte-for-byte extraction.
